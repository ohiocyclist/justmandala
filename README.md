# justmandala
Updated version of the Just Mandala project found here on GitHub ( https://github.com/florianjs/Mandala-JS/tree/master )

Like the other project, makes Mandalas using symmetry.

Also has a color chooser, a color importer from the image of your choosing, a random mandala maker, and an auto fill system

Uses React and Bootstrap

setup with node/npm,

npm i, 

then

npm run dev

Put a toe in the water on unit testing with jest, npm test

if you're not a fan of npm / React, there is a vanilla JS version that offers less functionality, but can just be served directly ( python -m http.server in the same folder as the 4 files and http://localhost:8000 in your browser for example )
